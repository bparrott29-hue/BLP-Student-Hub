# BLP Student Hub

Upload these files directly to the root of your GitHub repository:
- index.html
- style.css
- app.js

Then enable GitHub Pages from Settings -> Pages -> Deploy from a branch -> main -> / (root).

IMPORTANT: This version is a demo. It stores account passwords in browser local storage, so it is NOT suitable for real student information. For a real school deployment, use Supabase Auth and database security (Row Level Security).
