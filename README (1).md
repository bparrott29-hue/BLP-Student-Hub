# BLP Student Hub

This is a starter student dashboard that can be hosted on GitHub Pages.

IMPORTANT:
The included account system is a DEMO for learning. It stores passwords in the browser's local storage and is NOT appropriate for a real school deployment.

For a real public website, replace the demo login with Supabase Auth and store student data in Supabase with Row Level Security (RLS).

## GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and this README.
3. Go to Settings -> Pages.
4. Deploy from the main branch.
5. Open the generated GitHub Pages address.

## Search
To make people find it by typing "BLP Student Hub", give the site that title and name, then submit the site to search engines. Search engines may take time to index a new site. A custom domain can also be connected later.
